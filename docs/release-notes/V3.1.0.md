# OpenFetch 3.1.0

Neural Extractor V3 is now **OpenFetch by Brainbyte** — open-source media
downloader & toolkit.

Windows x64. Unsigned executable: Windows SmartScreen may warn on first run.

## What changes

- New name everywhere in the app: window title, header, dialogs, update
  messages, executable metadata, and icon.
- Existing settings, the dedicated YouTube browser sign-in profiles, and the
  optional PO helper activation are copied into OpenFetch on first start.
  Nothing is deleted from the Neural Extractor data folder.
- Neural Extractor 3.0.4 and later detect this release and update in place.
  The existing `NeuralExtractorV3.exe` file keeps its name so shortcuts keep
  working; it starts as OpenFetch.
- The updater now reports a moved release feed clearly instead of an invalid
  version error.
- Download behavior is unchanged: video, audio, playlists, subtitles,
  thumbnails, verified browser connection, and yt-dlp/FFmpeg integration work as
  in 3.0.8.

## Update and distribution status

Updates remain optional and always require a click. The package is verified by
size and SHA-256 against its manifest before installation, starts through a
detached helper, confirms startup, and rolls back automatically on failure.

The one-folder compliance candidate remains unpublished and its automatic
update remains unavailable. General compliance status remains **HOLD**; this
release does not represent a qualified legal review.

See [OPENFETCH-MIGRATION.md](../OPENFETCH-MIGRATION.md) for identifiers, the
upgrade path, and data migration details. Download OpenFetch only from the
official GitHub Release and verify the published checksum when possible.
